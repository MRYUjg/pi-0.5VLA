# ZhiXing 与 pi0.5 闭合协议核对

动作极性一致：LIBERO原策略/Panda与当前ZhiXing均以第7维正值闭合、负值张开。`LiberoOutputs`保留模型前7维；项目桥执行前5步，除既有限幅没有再翻转第7维。ZhiXing已有`format_action`内部使用`current_action -= speed * sign(action)`，这是对其负行程执行器的适配。

实际task0部署轨迹：正值约+1持续10步，Left_1从约−0.116移动至−0.910 rad闭合端；第20步模型约−0.993，Left_1回到约−0.452 rad、向张开方向变化。内部target=−1表示闭合端，与模型动作+1闭合不矛盾，不应再把模型输出反号。

方向正确不代表闭合行为等价。Panda是两指平移，ZhiXing是6联动关节及单执行器；指间距、指垫外形、速度和接触动力学不同。state最后两维也从Panda位移变为ZhiXing主动关节角。原生pi0_pick的指间距代理和米尺度门限未适配，详见原生工具适配边界。

更直接的本轮差异是模型闭合时机：同task0，Panda前10步动作第7维为−0.993至−1（保持张开）；ECO65＋ZhiXing两套配置前10步均约+0.995至+1（执行闭合）。因此当前失败不能用“底层正负号又反了”解释；新观测下的预测时机、视觉几何和接触行为仍需进一步定位。本轮没有改动闭合协议、速度或门限。
