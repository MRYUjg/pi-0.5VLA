# 独立验证失败定位：初始化穿插与接近跟踪

## 统计结论保持不变

r20固定新种子52100–52109：罐10/10、碗8/10。碗的两个失败均保留在分母中，未剔除、未补测替换。逐物理步审计通过说明证据自洽；本阶段要求每类至少9/10，因此**阶段验收未通过，不能放行规模采集或总体适配验收**。

## 52103：教师启动前，碗已被初始化接触弹出桌面

第一次记录显示“找不到可行原生物体抓点”。检查规划初态发现，碗中心已经在约[-1.036,0.969,0.025] m，落到桌面以外的地面，逆解位置残差超过0.5 m。这里的规划拒绝是结果，不是根因。

新增只读观察脚本 `probe_real_initialization_r1.py`，按同样的原生reset、legacy配置和120步quiet_hold执行，仅逐物理步记录目标接触，不写入姿态、不重摆物体、不重新抽取种子。

复现发现：

1. reset时刻碗位置约[-0.0356,0.1956,0.9700] m，碗与盘子碰撞几何已穿插，最大深度约10.82 mm。
2. 开始物理推进后，碗—盘单个接触点法向力峰值约1206.8 N；这是严重初始穿插的数值接触反力，不是夹爪输出的夹持力。
3. 约0.3 s后碗明显离开初始区域，约0.9 s落至地面；规划开始时已经不可达。
4. 观察复现静置后的全部qpos SHA256与原测试规划初态完全一致。确认该轨迹不是另一次随机摆放或探针改变动作造成的。

所以这一失败应归入**初始化几何有效性问题**，不能靠提高夹爪力、放宽逆解门限或用更大的安全高度修复。当前教师在规划阶段正确拒绝，但原先从静置后才开始的监测遗漏了这段接触过程；本次已用单独证据补齐这两个失败种子的reset→静置区间。

## 52104：接近抓点未到位

规划候选的离线逆解通过，实际接近阶段位置误差10.80 mm，超过4 mm门限；旋转误差0.0181 rad，低于0.03 rad门限。尚未闭合或抬升，不能归为夹爪夹不住物体。

同样的初始化观察可精确复现此例。该碗静置后仍在桌上，与52103的被弹出桌面不同。当前已定位到实际位置跟踪残差；其控制/位形原因还需要针对性验证，不能宣称已修复。

## 接触统计的适用区间

最终批次在**原始教师执行监测区间**内，记录到的机器人非目标接触（>0.1 N）与保护规则判定的非法接触计数均为0。但这不涵盖全部reset/quiet_hold时间，也不意味着整集没有碰撞：52103初始化中的碗—盘严重接触已由新增探针确认。

成功样本保持阶段双侧接触比例均为100%，其他支撑力为0。罐/碗最大穿透分别约0.308/0.500 mm，横向搬运最小净空约35.74/23.53 mm。这些指标支持已成功抓住并搬运原生物体，但不能掩盖初始化或接近阶段失败。

## 下一步的具体修复顺序

1. 将reset、静置、接近和带载阶段统一纳入证据采集，增加初始物体间穿插、桌面支撑、位移及可达性诊断。拒绝无效初态须单独计数，不能自动剔除后提高成功率。
2. 核对LIBERO任务官方初始状态集合与当前随机reset采样的差异，制定有效初态协议。当前记录证明了穿插和弹出链路，尚未把原因进一步归结到某一采样器代码行；不应直接重摆物体后声称原问题已解决。
3. 对52104做教师轨迹/位形的隔离回归，保持控制器、物理参数和门限受控；通过后另建候选，再用新的独立种子评估。
4. 初始化有效性与原生物体教师闸门通过后，再接RGB采集、数据审计与π0.5微调。目前没有训练数据放行。
