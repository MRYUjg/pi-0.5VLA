# 真实碗罐接入与复测协议 r4

承接协议r3，保存r9与r10的全部新种子结果，不覆盖原记录。r10两类结果为罐10/10、碗8/10，未达到两类均≥9/10。

开发发现与候选变更：

1. 初始倾斜碗的世界水平截面可能根本不穿过碗沿。补充碗局部坐标系上沿碰撞盒表面取样，使用当前物体实际姿态转换到世界坐标；主候选不可用时启用。
2. 在独立MjData中检查开口接近、下降的5个高度点，拒绝指垫与目标/非目标实体的穿透，不向实际episode写入关节逆解。r12已证明原下降推碗场景可变为真实双侧抓持与悬空保持。
3. 新增闭合末10个控制步双侧接触≥95%门限，未形成持续夹持时不抬升。这是新教师的更严阶段检查，不改上游冻结判据。
4. r13对碗候选优先考虑加权末端雅可比的最小奇异值：角速度部分用实际工具长度换算到米，作为避免难控姿态的启发式。搬运同时搜索原安全高度及额外30/60 mm高度，对中间路径做IK和相同条件评估；不再只取第一个存在逆解的姿态。这不是动力学可达性的证明，仍以实际执行门限为准。
5. r13碗教师旋转增量参数为0.12 rad；平移参数仍为抓取/抬升/保持20 mm、安全抬升/横移/投放30 mm。原实际TCP单步<20 mm、姿态<0.03 rad、抓取下降1 mm、穿透≤2 mm等门限不放宽，控制器和资产不改。

先以51100、51106及49100开发回归验证。候选通过后另锁定源哈希，再以52100–52109两类各10个新seed复测，目标各≥9/10，不补失败。若未通过或继续产生新版本，另登记版本和批次，不将旧失败抹除。

范围仍是两个原生任务的脚本教师与接触诊断，不是π0.5成功率、正式Spatial 10×20、训练数据放行或实机验收。几何函数的可用范围是当前原生box碰撞分解；其他碰撞类型明确拒绝。
