# 安全教师路径实施方案 r1

用户授权：按 ZhiXing 实际工具点、夹爪外形和带载包围盒，实现垂直抬升到位、横向搬运到位、下降投放。

只在本专用目录新增版本化教师与诊断证据；上游冻结资产、底层控制参数及验收标准不变。使用隔离 Python3.10/MuJoCo3.2.6 CPU 环境。

1. 从实际加载模型测量 grip_site、视觉外形和碰撞几何，分别记录。物体尺寸从当前仿真姿态求世界包围盒。不能将视觉外形误报为有效碰撞模型。
2. 在抓持保持后计算带载整体最低点相对 TCP 的偏移，按篮沿高度加安全余量生成垂直目标；在到位且实际净空充足后，才横向移至篮子上方。
3. 水平目标补偿物体中心相对 TCP 的偏移，下降目标根据物体底部和篮沿计算。未收敛、净空不足、撞篮或篮子移动均终止，不盲目投放。
4. 先用既有诊断 seed 做路径修复回归，再用新增 seed 检验可重复性。记录全部失败，不把规划拒绝或安全停止删除。
5. 逐阶段验证实际位置误差、接触、篮子位移和释放后谓词。本轮试块路径验证不替代真实 LIBERO 物体验收或 Spatial 200 次评测。

输出：版本化脚本、原始状态/动作与接触记录、几何快照、阶段目标及停止原因、最终验证报告。试验中发现的问题按新版本修正，不覆盖已经运行的版本。
