# 真实碗罐接入方案 r1

用户授权：下一阶段实现实际碗/罐几何接入抓取规划，重新验证成功率与接触行为。

本轮使用原生任务与对象：LIBERO Object task0（alphabet_soup→basket）以及Spatial task0（指定akita_black_bowl→plate）。不替换对象为试块，不改资产、质量、接触参数、底层控制器或上游冻结文件。

规划从实际加载的碰撞几何获取：对每个有姿态的box求闭合射线与几何的区间，再合并占据区间。罐采用包络外夹；碗采用分离的壳体区间捏沿，不能将空腔当作实心。抓取点、工具姿态、接近与下降可达性需分别检查。搬运沿用带载包围盒和分阶段安全教师。

先做开发场景并完整保留失败，然后冻结候选代码，以两类各10个新增seed独立复测。目标各至少9/10；未通过如实记录。初态采用原生reset，不强制旋转对象对齐夹爪，不使用正式Spatial保留测试集。

本地新增验收协议沿用抬升≥30mm、2秒保持中高度≥25mm、双侧接触≥95%、无外部支撑、穿透≤2mm、每控制步TCP位移<20mm、阶段到位与姿态门限、释放后20步稳定<5mm及原生谓词。碗放盘子的on谓词不能错误套用篮子三维包围盒contain判定；因此使用原生目标谓词并检查实际目标支撑接触。这是新增任务协议，不改写上游审核逻辑。

保存模型、初态、源指纹、全部实际动作、每物理步接触与力、阶段结果；进程必须正常退出。诊断为无渲染CPU运行，不生成训练数据。单任务/几何验证不代表Spatial 200次或实机验收。
