# r18 候选独立验证方案

## 范围与前置条件

本方案继承 r1 的实际 LIBERO 碰撞几何、分阶段力/接触测量与成功门限。先要求 r18 在碗49100、51100、51106以及罐49100共4例开发回归中全部通过，且原始证据审计通过，随后才运行本方案的新种子。回归失败不能算作独立测试，也不能被删除。

候选为 `real_object_teacher_r18.py`，入口 `run_real_control_ab_r5.py`，运行时使用用户授权的 `eco65_no_extra_pd`。初始化仍为 legacy，静置后才切换。生产默认配置、OSC参数、接触/摩擦/质量、模型资产、原验收门限不变。

## 与仅改PD的 A/B 的区别

r15 A/B只改额外关节PD，碗B组仅1/3全流程通过。r18还修改了教师动作：去掉 kp0 运行下的积分补偿；保留原教师误差换算，平移指令上限搬运/下降30 mm、其他20 mm，旋转0.12 rad；阶段转移需连续5步满足原误差门限且实际TCP每步移动小于0.5 mm。指令上限不等于实际单步位移，实际位移仍必须小于20 mm。

这属于新的组合候选，其完整成功率不能归因于仅删除PD。不修改生产采集程序，不生成训练数据。

## 预注册测试

- 原生罐：LIBERO Object task0，alphabet_soup → basket。
- 原生碗：LIBERO Spatial task0，black_bowl between plate and ramekin → plate。
- 每类种子52100至52109，共20个独立进程，最多2并发，纯CPU。
- 同一种子只运行一次正式测试；失败保留，不替换，不补抽种子。
- 两类分别至少9/10，且逐物理步审计通过，才算本阶段通过。仍不是Spatial十任务×20次正式验收。
- 碗必须夹持实际碗壁，不能用实心包围盒替换；倾斜初始化保留。罐目标初始位置在该原生任务中基本固定，不能将场景种子数写成不同罐抓取位置数。

全部原门限继续有效：双侧持续接触、抬升30 mm、2秒悬空保持、无其他支撑、穿透不超过2 mm、实际单步TCP移动小于20 mm、先安全抬升再横向搬运再下降、实际到位、非目标接触保护、稳定原生任务成功窗口、接收物体位移不超过5 mm。

审计使用 `verify_real_object_r6.py`，统计使用 `summarize_real_object_r3.py`。运行前记录教师、启动器、检查脚本及本方案的SHA256；冻结只表示证据完整，不能代替任务验收。
