# r20 候选独立验证方案

本方案接续原生碗/罐几何接入方案，取代未满足回归前置条件的r18独立测试计划；旧方案和失败证据保留。

候选源码：`real_object_teacher_r20.py`；启动器：`run_real_control_ab_r7.py`；数值审计：`verify_real_object_r6.py`；统计：`summarize_real_object_r3.py`。

运行时使用用户已授权的 `eco65_no_extra_pd`，两类都先在legacy下初始化、静置，再在首条教师动作前切换。生产默认配置、OSC参数、资产、摩擦/质量/接触参数均不改。

碗教师关闭积分补偿，位置误差除以0.02、旋转误差除以0.10；搬运/下降平移指令上限30 mm，其他20 mm，旋转0.12 rad。阶段切换须连续5步满足原位置/姿态误差门限且实际TCP每步移动小于0.5 mm。罐恢复r15已验证的教师动作及到位行为。该组合候选不同于“仅改PD”的A/B，不可混淆因果归因。

## 前置回归

r20碗49100、51100、51106及罐49100共4例必须全部通过，且证据审计通过。失败保留，不计入新种子成功率。r19碗与r20碗逻辑相同，但仍重新运行r20回归确认。

## 预注册独立测试

- 批次：`real_objects_validation_20261002_r3`。
- 两类各使用新种子52100–52109，共20个独立进程；每个只测一次，不替换失败，不补抽种子；纯CPU最多2并发。
- 罐：LIBERO Object task0，alphabet_soup → basket；碗：LIBERO Spatial task0，black_bowl between plate and ramekin → plate。
- 分别达到至少9/10且逐物理步审计通过，才算本阶段两任务验证通过。
- 原生碰撞资产、倾斜初始化均保留；罐目标在原任务中的初始位置基本固定，种子数量不等于不同罐抓取位置数量。
- 保留全部原门限：闭合持续双侧接触、抬升30 mm、40步悬空保持、无其他支撑、穿透≤2 mm、实际单步TCP位移<20 mm、垂直抬升到位→横向搬运到位→下降投放、非目标接触保护、接收物体位移≤5 mm、20步稳定原生任务成功与支撑接触。

运行前保存本方案和源码SHA256。冻结与审计通过仅说明文件和记录完整，实际任务通过按成功统计判断。这不是π0.5模型测试、训练数据采集、十任务×20次Spatial最终验收，也不是实机负载验证。
