# r16 教师动作稳定化开发回归方案

已获用户授权执行 kp=3/0 隔离对照及后续验证。r15 配对碗 A/B 中，kp0 的三个场景均通过抬升和横向搬运，仅一例完成投放；两例下降/松爪期间出现接触，因此尚不满足进入新种子验收的条件。

逐步记录显示原教师把位置误差除以0.02、旋转误差除以0.05，再由控制器乘以0.05/0.5，且继承了用于抵消关节弹簧的积分项。关闭额外PD后，末段出现明显过冲；这是独立于A/B的教师修正假设，需要单独回归，不能将其效果归因于仅改PD。

r16仅在已有kp0隔离运行时按实际动作尺度生成增量，关闭教师积分补偿，平移/旋转每步指令上限8 mm/0.02 rad；阶段转移增加连续5步满足既有位置姿态门限、实际TCP位移小于0.5 mm的稳定条件。保持物理控制器、OSC参数、资产和原有验收门限不变。没有采集训练数据或改变采集程序。

先以碗49100/51100/51106和罐49100开发回归；全部通过后冻结新候选，用52100–52109做两类各10次独立测试。开发回归不计入独立成功率。若失败，保留并进一步定位，不能宣称验收通过。
