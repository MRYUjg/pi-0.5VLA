## 1. 措施 A-1：容差标定（`--calibrate --repeats 3`）

```
[标定] n4v5_libero_object_t0_s2_0002.npz  重复 3 次
  run 1: {'arm': 0.026258404, 'grip': 0.039490139, 'obj_pos': 0.139501689, 'obj_rot': 1.586216107}
  run 2: （与 run 1 逐位相同）
  run 3: （与 run 1 逐位相同）
[标定] 重复离散度 = {'arm': 0.0, 'grip': 0.0, 'obj_pos': 0.0, 'obj_rot': 0.0}
[标定] 渲染离散度 = {'agentview': 0.0, 'wrist': 0.0}
```

**结论（重要）**：同一 episode 同配置重复回放**离散度为 0**，回放是**逐位确定性**的。
因此：

- 复核 §2.3.2 的判断成立 —— **不能用"接触敏感/混沌"解释数百毫米偏差**。若真是混沌，重复回放不会逐位相同。
- 按代码既定规则，容差 = 离散度 + 1e-9 = **1e-9**，即"任何偏差都归因于未恢复的状态，不被容差吸收"。
- 产物：`configs/n4_audit_tolerances.json`。

### 2.1 客观结论

- **4 类注入全部被拒绝** ✓（动作错位、尾段替换、腕图错位、物体状态破坏）
- **但干净样本也没通过**，脚本自身给出警告：

  注入坏数据同样不达标** —— 这本身不构成判别力证据。

### 2.2 逐项比对：只有 2 类负对照提供了**增量**证据
