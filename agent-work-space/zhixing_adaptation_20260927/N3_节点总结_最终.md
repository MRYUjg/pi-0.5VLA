## 3. 三个「抓不住」的真实原因

> 这一节是本节点最重要的产出：**"抓不住"不是夹爪不行，而是 2 个资产缺陷 + 1 个我方台架假象。**

### 3.1 主因：执行器**没有力上限**（robosuite 里唯一一个）

`zhixing_gripper.xml` 原文：`<position name="gripper" joint="Left_1_Joint" ctrlrange="-0.91 0" kp="100"/>`

| 夹爪 | actuator |
|---|---|
| `PandaGripper` | `kp="1000" forcelimited="true" forcerange="-20 20"` |
| `RethinkGripper` | `kp="1000" forcelimited="true" forcerange="-20 20"` |
| **`ZhixingGripper`** | **`kp="100"`，无 `forcelimited`、无 `forcerange`** ← 唯一 |

位置伺服一路压过自身关节限位，实测后果：

| 指标 | 无限力（修复前） | 限力 ±2 N·m（修复后） |
|---|---:|---:|
| `Left_1_Joint` 实际角 | **−0.96487**（自身 range `[-0.91, 0]`，**超限位**） | −0.6174 |
| 指垫↔试块 Σ法向力 | **94.9 N**（真机额定 23 N 的 **4.1×**） | 26.0 N |
| 对**刚体**的穿透 | **−15 ~ −20 mm** | **−0.82 ~ −1.12 mm** |
| 接触法向 | `[0.098, −0.466, **0.879**]` 近**竖直** | `[0, ±1, 0]` **纯横向** |
| 指垫内面高度 | 跑到试块**顶面之外**（骑到物体上） | 在试块高度内 |
| 试块↔桌面法向力 | **32.3 N**（被按进桌面） | 0.74 N |
| 有效摩擦 μ_eff | **0.246** | — |

**机理链**：
```text
无力上限 → 压过自身限位 → 指垫压进刚体 6~20 mm
        → 指垫滑到物体顶面之上，不再侧向对夹
        → 接触法向由 ±y 翻成近 +z：夹爪在把物体按进桌面
        → 有效摩擦塌到 0.246 → 抬升带不走
```

### 3.2 次要因：限力后**闭合极慢**，固定步数会让抬升在"夹爪还张着"时开始

| | 无限力 | 限力 ±1.33 |
|---|---:|---:|
| 600 子步后 `Left_1` | 已到 −0.91 并压过限位 | **只有 −0.097** |
| 抬升开始时指垫↔试块接触 | 2 处（压穿状态） | **0 处，ΣfN = 0** |

逐步追踪显示：抬升到 ramp **10/25** 时指垫才第一次碰到试块，那时已上升 ~20 mm，正好在**顶棱**附近，随即滑过。
→ **台架时序问题**。修法：**闭合到停住**（3300 子步 → `Left_1=−0.6174`）。

### 3.3 台架假象（我方）：运动学瞬移抬升传不了载荷

原抬升实现 `step_hold` 是**直接改写机械臂 qpos 并清零 qvel**（运动学覆盖），不是施力。
即使夹持已完全正常（26 N 横向、穿透 3.6 mm）：

| ramp | 指垫内面 z | 试块 z（Δ） | 接触 | ΣfN |
|---|---:|---:|---:|---:|
| 闭合后 | 0.9455 | +6.45 mm | 2 | 26.47 N |
| 20/25 | 0.9863 | +4.42 mm | 2 | 25.58 N |
| 25/25 | 0.9961 | **+3.70 mm** | 2 | 25.80 N |

**指垫升了 50 mm，试块不但没跟，反而沉了 2.75 mm**，而法向力全程稳定 ~26 N。

**用外力（而非动臂）测真实保持力**：

| 配置 | Σ法向力 | **保持力 F_hold** | 试块自重 | 比值 |
|---|---:|---:|---:|---:|
| 无限力 | 94.9 N | 16.0 N | 1.442 N | 11.1× |
| 限力 23 N 等效 | 26.0 N | **8.0 N** | 1.442 N | **5.5×** |
| 限力 12 N 等效 | 14.6 N | **7.0 N** | 1.442 N | 4.9× |

**夹爪一直都能撑住自重 5~12 倍的竖直载荷** —— 所以"抬升带不走"是**抬升方式**的问题。

**改用 robosuite 的 OSC 控制器闭环（力驱动）**：

| 抬升方式 | 结果 |
|---|---|
| IK 位移瞬移（原实现） | **0/10**（抬升 −0.9 ~ +3.7 mm） |
| **力驱动 OSC 闭环** | **5/5**（抬升 **+50.6 ~ +56.9 mm**） |

## 4. 结构核实（为什么指垫加在这两个指节上）

**CRT-CTAG2F90 = 单驱动二指平行四连杆（four-bar）自适应夹爪**：

```text
base_link
  ├─ Left_1_Link   ──(Left_1_Joint，唯一被驱动)
  │    ├─ Left_Support_Link ──(Left_Support_Joint)      ← ★ 指垫板（接触体）
  │    └─ Left_2_Link       ──(Left_2_Joint)            ← 平行连杆
  ├─ Right_2_Link           ──(Right_2_Joint)           ← 平行连杆
  └─ Right_1_Link  ──(Right_1_Joint)
       └─ Right_Support_Link ─(Right_Support_Joint)     ← ★ 指垫板（接触体）
```

驱动靠 `<equality>`（5 条 joint equality + 2 条 connect 四连杆闭环），**不是** 6 个执行器。

**逐 body 核对编译模型：只有这两个 `Support_Link` 带碰撞 geom，其余全为仅视觉。**

**关键交叉验证**：厂商 URDF 在指节上挂着一个**独立的 `Left_Pad_Link`**（fixed，原点
`(−0.024010, 0.041244, 0)`），与实测内侧面中心 `(−0.025577, 0.043602)` 相距仅 **2.9 mm**
→ **mesh 里本就含橡胶垫零件**，缺的是它的**接触材料属性**，不是几何。

**✅ 已证明能抓**：包络内的**实体**，宽 ≤ ~85 mm、高 ≥ ~45 mm（保证指尖净空），抓取—抬升 5 cm—保持 2 s—放回全流程成功。

| 限制 | 事实 | 性质 |

| **任务物体全部超包络** | 遍历 `libero_spatial` 十个任务：黑碗 111.8 / 圆盅 89.3（余量 0.66）/ 饼干盒 20 mm 厚 / 盘子 137.6 / 灶钮 95.3 —— **可抓候选 = 0** | **任务集口径问题**，需决策 |

## 8. 方法学沉淀（三条，值得后续节点复用）

1. **绝不能用策略成功率判定夹爪好坏**：π0.5 装 ZhiXing 会恒输出 +1 闭合（视觉 OOD），
   与夹爪物理能力无关。本节点全程脚本专家 + 底层控制。
2. **测"抓持"必须用外力而非动臂**：运动学瞬移（直接改 qpos）传不了载荷，
   会把「夹爪能撑 5~12 倍自重」误判成「抓不住」。用力驱动（OSC）或 `xfrc_applied`。
3. **给执行器加限力后必须重新标定时序**：闭合时间从"瞬间"变成 ~1 s，
   所有固定步数的等待都要改。同理，`n3_grasp_test.py --part A` 的 settle 已参数化
   （`--a-settle`，默认 80 env step；判据本身 std < 0.5 mm 未改动）。
