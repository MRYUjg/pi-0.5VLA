## 1. §6 指出的三个不足（逐条核对为真）

`n4_collect.py` 旧实现：

1. `success = ep.done and in_basket` **没有**包含后面算出的 `post_release.stable`
   → 稳定性不足的轨迹会被先存成 success。
2. `stable` 只要求"观察计数 > 0 + 终点谓词/位置成立 + 首尾漂移小"，
   **不要求跑满 40+30 步、不要求窗口连续成立、无单步位移/速度限制**。
3. `predicate_true_at_release` 在**整段观察结束后**才赋值，
   实际不是释放时刻的值；审计又**直接信任**元数据里的 `stable`。

## 2. 已实现的修改

### 2.1 采集侧（`scripts/n4_collect.py`）

| 复核要求 | 实现 |
|---|---|
| 分别记录释放瞬间 / 沉降结束 / 观察窗口的状态 | `object_center_at_release` + `predicate_true_at_release` 改为**在释放那一刻**取；`object_center_at_settle_end` 在沉降段结束时取；窗口逐步轨迹 `center/pred/inside` 全程记录 |
| 稳定窗口要求**持续满足**谓词/区域条件 | `window_predicate_all_true`、`window_inside_all` —— 窗口内**每一步**都必须为真 |
| **最大位移与速度限制** | `tail_max_step_disp_mm` < 5.0 mm/步、`tail_max_speed_m_s` < 0.05 m/s |
| 缺步骤不得放行 | `settle_steps ≥ 40`、`retreat_steps ≥ 30`、`window_steps ≥ 70`、`window_complete` |
| 稳定性纳入**正式成功门槛** | `success = ep.done and in_basket and pr["stable"]` |

新增常量：`POST_RELEASE_MAX_STEP_DISP_MM=5.0`、`POST_RELEASE_MAX_SPEED_M_S=0.05`、
`POST_RELEASE_MIN_WINDOW_STEPS=70`。

### 2.2 审计侧（`scripts/n4_audit.py`）

| 复核要求 | 实现 |
|---|---|
| **在回放中重新计算**、不直接信任元数据 | 按同一判据从原始字段**独立重算**（`post_release_recomputed_stable`），并新增 `post_release_metadata_agrees` 要求"元数据自报 == 独立重算" |
| 缺步骤或中途异常不能以最终一个成功点放行 | `post_release_no_missing_steps` 要求 40+30+70 步齐全 |

## 3.5 `servo()` 超时 → 失败（本轮新增）

复核原文："检查 `servo()` 返回值，超时必须触发失败或有记录的重规划。"

**问题**：`transport` / `place` 两处调用写成 `_, pe["transport"] = ep.servo(...)`，
把收敛标志 `ok` **直接丢弃**，于是"没到位"和"到位"在结果里完全一样。

**实现**：捕获 `ok`，汇总为超时清单，并把"无超时"并入成功门槛：

```python
TIMEOUT_PHASES = ("approach", "descend", "lift", "transport", "place")
pe["servo_timeouts"]   = [{"phase": ph, "steps": n} for 未收敛的 phase]
pe["servo_no_timeout"] = bool(not pe["servo_timeouts"])
success = ep.done and in_basket and pr["stable"] and pe["servo_no_timeout"]
```

**复验（tag `n4v8`，目标 1 条）**：

```
→ ❌失败 谓词=False | → ❌失败 谓词=True | → ❌失败 谓词=True
→ ❌失败 谓词=True  | → ❌失败 谓词=True | → ❌失败 谓词=True
[N4] 成功 0/1（尝试 6 次）→ NOT_ENOUGH
```

失败记录实测：

```
servo_no_timeout = False
servo_timeouts   = [{"phase":"transport","steps":220},{"phase":"place","steps":160}]
phase_end        = {"approach":22, "descend":18, "transport":[false,220], "place":[false,160]}
```

**这 5 条里任务其实都成功了**（谓词 True、几何入篮 True），但按复核口径
"关键阶段不依赖超时放行"，现在一并判失败。

> **重要后果**：教师当前**无法产出可验收的成功示范** —— 6 次尝试 0 条通过。
> 措施 D（"冻结后重新采集 ≥5 条"）因此**被卡在教师修复上**，
> 而按复核要求不得用缩短等待 / 增大上限 / 放松条件绕过。
