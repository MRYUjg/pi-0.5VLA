# ZhiXing 夹爪为什么抓不住物体？—— 根因诊断

| 项目 | 内容 |
|---|---|
| 日期 | 2026-09-27 |
| 触发 | N3 重做中「标准实心试块在 30/50/70 mm 全部 0/10」，需查清是夹爪本身还是别的原因 |
| **结论** | **三个原因叠加：2 个真实的资产缺陷 + 1 个我自己台架的假象。夹爪并非"天生抓不住"。** |
| 修复后验证 | 力受限 + 闭合到停住 + **力驱动抬升** → **50 mm 10/10、70 mm 10/10**（30 mm 5/10） |
| 资产改动 | **无**（全部在测试进程内验证） |

---

## 0. 一句话答案

> ZhiXing 的**执行器没有力上限**（robosuite 里唯一一个），于是位置伺服一路压过自己的关节限位，
> 用 **94.9 N**（真机额定 23 N 的 4.1 倍）把指垫压进刚体试块 **6~20 mm**，指垫从物体**侧面滑到顶面**、
> 接触法向由横向翻成竖直，物体被按进桌面 —— 有效摩擦塌到 0.246，于是"抓不住"。
> 而**我原来的抬升方式是直接改写机械臂关节角（运动学瞬移）**，它本身就传不了载荷，
> 把夹爪的真实能力也一并掩盖了。

---

## 1. 原因一（真实缺陷，主因）：执行器**没有力上限**

`robosuite/models/assets/grippers/zhixing_gripper.xml`：

```xml
<actuator>
  <position name="gripper" joint="Left_1_Joint" ctrlrange="-0.91 0" kp="100"/>
</actuator>
```

对照仓库里其它夹爪：

| 夹爪 | actuator |
|---|---|
| `PandaGripper` | `kp="1000" forcelimited="true" forcerange="-20 20"` |
| `RethinkGripper` | `kp="1000" forcelimited="true" forcerange="-20 20"` |
| **`ZhixingGripper`** | **`kp="100"`，无 `forcelimited`、无 `forcerange`** ← 唯一 |

### 实测后果（试块 60×50×70 mm，实心，重 0.147 kg / 1.442 N）

| 指标 | 无限力（现状） | 限力到 23 N 等效 |
|---|---:|---:|
| `Left_1_Joint` 实际角度 | **−0.96487** | −0.60680 |
| 该关节自身 range | `[-0.91, 0]` → **超出限位 0.055 rad** | 正常范围内 |
| 指垫↔试块 Σ法向力 | **94.94 N**（真机额定 23 N 的 **4.1×**） | 26.04 N |
| 对**刚体**的穿透 | **−17.69 / −9.56 mm** | −3.59 / −3.53 mm |
| 接触法向 | `[0.098, −0.466, **0.879**]` / `[0.093, 0.651, **0.753**]` 近**竖直** | `[0, **1**, 0]` / `[0, **−1**, 0]` **纯横向** |
| 指垫内面所在高度 | z=0.9786 / 0.9845 → **在试块顶面(0.9724)之外** | z=0.9447 / 0.9459 → **在试块高度内** |
| 试块↔桌面法向力 | **32.30 N**（被按进桌面） | 0.74 N |
| 有效摩擦 μ_eff | **0.246** | 0.331 |

**机理链**：

```text
无力上限 + kp=100 位置伺服
  └─→ 压过自身关节限位（-0.965 < -0.91）
       └─→ 指垫压进刚体 6~20 mm（物理上不可能，是软接触被压穿）
            └─→ 指垫相对物体上滑，内面跑到物体**顶面之上** —— 不再是侧向对夹
                 └─→ 接触法向由 ±y 翻成近 +z：夹爪在把物体**按进桌面**
                      └─→ 有效摩擦塌到 0.246 → 抬升带不走
```

这也解释了此前的 `Nan, Inf or huge value in QACC at DOF 3` 数值发散警告。

## 2. 原因二（真实缺陷，次要）：限力后**闭合极慢**，固定步数会在"夹爪还张着"时就开始抬升

给执行器加上真机等效力矩上限（±1.33 ≈ 23 N）后：

| | 无限力 | 限力 |
|---|---:|---:|
| 600 步后 `Left_1_Joint` | 已到 −0.91 并压过限位 | **只有 −0.097** |
| 抬升开始时的指垫↔试块接触 | 2 处（压穿状态） | **0 处，ΣfN = 0** |

逐步追踪（限力 + 固定 600 步闭合）显示：抬升到 **ramp 10/25** 时指垫才第一次碰到试块，
而此时指垫已经上升了 ~20 mm，正好在试块**顶棱**附近，随后立刻滑过去。

> 这是**台架时序**问题，不是夹爪问题：真实夹爪会先闭合到位再抬。
> 修法：**闭合到停住**（`close_until_stall`，3650 步后 `Left_1=−0.609`）。

---

## 3. 原因三（**我自己台架的假象**）：运动学瞬移式抬升传不了载荷

原来的抬升实现是 `step_hold`：**直接改写机械臂 qpos 并把 qvel 清零**再 `sim.step()`。
这是运动学覆盖，不是"施加力让手臂抬起来"。对软接触而言，求解器看到的是位置阶跃而非力。

限力 + 闭合到停住之后（夹持本身已经完全正常），逐步追踪：

| ramp | 指垫内面 z | 试块 z（Δ） | 接触 | ΣfN | Σ切向_z |
|---|---:|---:|---:|---:|---:|
| 闭合后 | 0.9455 | **+6.45 mm** | 2 | 26.47 N | −1.42 |
| 10/25 | 0.9656 | +6.19 mm | 2 | 25.55 N | −5.96 |
| 20/25 | 0.9863 | +4.42 mm | 2 | 25.58 N | −1.60 |
| 25/25 | 0.9961 | **+3.70 mm** | 2 | 25.80 N | −0.03 |

**指垫升了 50 mm，试块不但没跟，反而沉了 2.75 mm**，而法向力全程稳定在 ~26 N。
即：横向夹持是真的，但**切向传不上来**。

**对照测量（用外力而非动臂）**：给试块施加已知竖直外力 `d.xfrc_applied`，找拉动阈值：

| 配置 | Σ法向力 | **保持力 F_hold** | 试块自重 | 比值 | μ_eff |
|---|---:|---:|---:|---:|---:|
| 无限力（现状） | 94.9 N | 16.0 N | 1.442 N | 11.1× | 0.246 |
| 限力 23 N | 26.0 N | **8.0 N** | 1.442 N | **5.5×** | 0.331 |
| 限力 12 N | 14.6 N | **7.0 N** | 1.442 N | 4.9× | **0.565** |
| 加硬+高摩擦 | 151.0 N | 17.5 N | 1.442 N | 12.1× | 0.101 |
| 限力23N+加硬+高摩擦 | 26.5 N | **11.5 N** | 1.442 N | **8.0×** | **0.499** |

**夹爪一直都能撑住自重 5~12 倍的竖直载荷** —— 所以"抬升带不走"是**抬升方式**的问题。

**改用 robosuite 的 OSC 控制器闭环（力驱动）抬升后**：

| 抬升方式 | 结果 |
|---|---|
| IK 位移瞬移（原实现） | **0/10**，抬升 −0.9 ~ +3.7 mm |
| **力驱动 OSC 闭环** | **5/5**，抬升 **+50.6 ~ +56.9 mm**，保持 +50.8 ~ +57.0 mm |

## 4. 修复后的完整验证

在**同一标准试块**上，同时施加三项修正（全部在测试进程内，未改资产）：

1. 执行器力矩上限 ±1.33（≈ 真机 23 N 等效）；
2. 闭合到停住（而非固定 600 步）；
3. **力驱动 OSC 闭环抬升**（而非运动学瞬移）。

| 试块宽度 | 结果 | 闭合净距 | 穿透 | 抬升 |
|---|---:|---:|---:|---:|
| 30 mm | 5/10 | 25.3 mm | −4.6 mm | +51~54 mm（成功轮） |
| **50 mm** | **10/10 ✅ PASS** | 47.3 mm | −3.6 mm | **+50.6~56.9 mm** |
| **70 mm** | **10/10 ✅ PASS** | 67.7 mm | −3.4 mm | **+52.0 mm** |

**总体 verdict = PASS**（50/70 mm 满 10/10）。30 mm 的 5 轮失败伴随穿透 −24.6 mm，
说明**窄物体仍会触发压穿**——限力值/接触刚度对窄物体还需再调。

## 5. 修正后的因果归属

| 之前的判断 | 现在的判断 |
|---|---|
| 「夹爪抓不住物体」 | ❌ 过强。夹爪**能**抓：50/70 mm 满 10/10，保持力是自重的 5~12 倍 |
| 「指垫缺专用 box 是主因」 | ⚠️ 部分。它是真实缺陷（见 §6），但**不是**主因：补了专用 box 仍 0/10 |
| 「接触模型坏」 | ✅ 真，具体是**执行器缺力上限**导致压穿，而非几何 |
| 「有效摩擦只有 0.246」 | ✅ 真，但它是**压穿的后果**，不是原因 |
| — | 🆕 **我原来的抬升方式是运动学瞬移，属台架假象**，是 0/10 的直接贡献者之一 |
