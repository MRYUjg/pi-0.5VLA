## 验证与后续版本变更

冻结工具依赖 Python ≥3.9（`Path.is_relative_to`）。**服务器系统 `python3` 是 3.8.10，直接运行会崩溃**；必须用 `libero:latest` 容器（Python 3.10）执行，在仓库根目录：

```bash
docker run --rm --network none -v "$PWD:/app" -w /app --entrypoint /bin/bash libero:latest \
  -c "cd /app && python3 agent-work-space/zhixing_adaptation_20260927/scripts/n0_freeze.py verify"
docker run --rm --network none -v "$PWD:/app" -w /app --entrypoint /bin/bash libero:latest \
  -c "cd /app && python3 agent-work-space/zhixing_adaptation_20260927/scripts/n0_freeze.py verify --check-archive"
```

`manifests/freezes/<version>/` 为 `root:root` `0700`，以 `vipuser` 身份直接读取会被拒绝；容器以 root 运行故上述命令可行，手工核对哈希需 `sudo`。

`verify --check-archive` 需要 `files.tar.gz`（约 438 MB），该文件与 `raw/` 只在服务器保留；**在只做文档镜像的本机执行 verify 会报 `sealed_file_mismatch:files.tar.gz`，属缺件而非漂移**（本机 git 检出还存在若干行尾差异）。

默认只检查，不改指纹。源码或受管配置变化必须显式建立新版本，已有版本不可覆盖。删除受管源码必须在退役清单中填写前一版 SHA256 和原因，并在 `create --version 新版本 --retire-list 清单路径` 时明确指定。
