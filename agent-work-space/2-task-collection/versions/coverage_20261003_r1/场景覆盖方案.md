# 场景覆盖方案

版本：coverage_20261003_r1；日期：2026-10-03。由用户“继续，补充场景覆盖”授权，新增初始化采样变体；保留pilot_20261003_r1冻结文件和全部旧数据。

## 问题与修改范围

原任务目标采样区域为50×50mm。采样器启用ensure_object_boundary_in_range后，从两端扣除目标horizontal_radius，使目标采样区间退化为中心点。仅换种子不能补充目标位置覆盖。

本版在reset的原生placement sampler返回后，显式设置目标罐、篮子的初始XY，并对目标原生四元数左乘世界Z轴偏航增量；随即由原生reset流程应用初态。只在初始化阶段调整，不在动作执行期间写入物体或机械臂qpos。其余物体仍由原生采样器初始化。

这是“原生资产、同一任务目标、受控初始化变体”，不冒充原始LIBERO基准分布。覆盖范围按物体中心解释，不声称完整物体轮廓仍包含在原50mm小区域内。保存初始化覆盖前后参数、静置后的实际位姿和清单指纹。

机器人、夹爪、OSC、额外PD运行profile、r20专家及原r6审计判据均保持原样。新增初始化检查是数据放行的补充条件，不放宽原物理判据。主源码冻结范围增加BDDL，场景清单随版本归档。

## 预登记场景

唯一依据为scenes.json，开跑后不根据教师成败换场景。

- train：9格网格，X={−140,−120,−100}mm、Y={−260,−240,−220}mm；目标偏航增量−20/0/+20°交错组合；篮子X=−6/0/+6mm、Y=254/260/266mm。
- validation：3个不与训练位置重合的插值位置，偏航−10/+10/0°，篮子位置另设；只用于后续开发验证。
- test：3个预留位置；本轮只检查初始化可行性，不运行教师或生成训练轨迹。不能把这3个单任务场景替代Spatial正式200次测试。
- 相机、光照、纹理、物体种类和质量不随机化。本阶段首先补足位置与朝向覆盖。

## 执行顺序与验收

1. 原版冻结验证通过；比较原生采样器输出/reset/静置状态，留存根因证据。
2. 15个场景初始化预检，逐物理步检查静置期间物体间或机器人—物体的非支撑穿透；阈值2mm，地面正常支撑不算非法接触。检查目标中心静置漂移≤5mm、数值有限、无物理warning、初始任务未成功。记录接触与位姿，不把初始化合格写成任务成功。
3. 两个网格角落做无图像专家预检，仅作开发回归，不与正式试采合并统计。
4. 固定9train＋3validation，共12次正式试采，最多2并发。保留每次尝试及失败，不补抽、不更换种子。
5. 全部轨迹执行相同初态重建与真实动作回放，沿用T/T+1、具名夹爪状态、原物理门限、正常退出要求；抽查每条5帧双视角像素。失败轨迹不进训练清单。
6. 汇总实际接受的空间格点、XY跨度、四元数、篮子位置和split。用毫米级量化位姿去重，禁止把浮点哈希差异当作有效覆盖。
7. 训练、验证按scene ID保持独立，不按帧拆分。旧pilot数据独立保留，不自动混入新训练清单；预留test禁止该采集入口执行。后续需依场景指纹防止泄漏。

目标：12个场景完成有记录的尝试；初始化覆盖15个真实不同目标中心，训练9格得到合格示范才报告9/9覆盖。若有失败，按真实覆盖数报告缺口，不降低标准。本轮不训练π0.5、不扩展碗任务或控制器。
