# 单任务试采方案

版本：pilot_20261003_r1；日期：2026-10-03。上游采用 1.3-zhixing_gripper_solve 的 r20 专家。版本在实施验证结束后冻结，开发批次分别记录运行时文件指纹；不得覆盖历史批次。

## 范围与选择

本次任务是把已验证的 ECO65＋ZhiXing 抓放能力接入训练原始数据采集，并执行小批试采。首任务选 LIBERO Object task 0：pick_up_the_alphabet_soup_and_place_it_in_the_basket。它在上游新种子验证为10/10；Spatial task 0 碗为8/10，仍有初始化及接近失败，暂不把碗失败混入此任务。本阶段不代表 Spatial 十任务验收，也不启动模型训练。

采用原生罐、篮子及完整场景；不改机器人、夹爪、物体碰撞资产或OSC增益。沿用已授权且已验证的隔离 profile：legacy 初始化并静置120步，首条教师动作前切换 eco65_no_extra_pd，夹爪 speed=0.01。生产默认配置不切换。使用脚本专家特权状态生成动作；该状态用于教师及审计，不作为新增模型视觉输入。

## 依赖恢复

服务器原 zhixing_adaptation_20260927 目录缺失，r20 间接依赖的 n3_grasp_test、n3_osc_full_chain、n4_collect 无法按旧路径导入。本次从本机镜像复制到新版本 vendor，三文件 SHA256 与 real_objects_validation_20261002_r3 成功记录完全一致。r20、safe_teacher_r8、loaded_diagnostics_r5、eco65_expert_validation、verify_real_object_r6 从服务器复制；保留原内容及判据。只通过导入路径加载，不重建被清理的旧目录。隔离 Python3.10/MuJoCo3.2.6 运行时继续使用 1.3 目录的环境。

## 实施与门槛

1. CPU OSMesa 双相机预检：256×256 RGB，正常 close 与进程退出，禁用强制退出绕过。
2. 原成功种子52100完整记录，对照原逐步动作、qpos、阶段和任务门限，检查记录器未改变教师行为。
3. 锁定试采种子53100–53104，五次尝试全部保留，不替换失败、不补抽。此批仅为采集开发数据；未来正式200次测试另用冻结种子和场景哈希。
4. 每条重新 reset(seed)，执行原准备动作和全部7维OSC动作，逐帧核对状态、原生成功值；抽五个观测点双相机像素比较。回放不注入保存的qpos。
5. 沿用上游r6数值审计，再检查数据格式、有限值、时间/动作/物理记录一致性、具名夹爪关节、图像非空与实际退出码。只有全部通过的成功轨迹进入 accepted 清单。

若不足五条合格，报告真实数量，保留失败原因，先修复采集链路问题。任何控制或教师行为修改须另立版本，不能用放宽审计门限达标。

## 数据契约

每个episode独立HDF5，逐帧压缩写入。进行中使用trajectory.partial.h5，正常收尾才改名trajectory.h5；真正放行还要求宿主机记录退出码0。

- observations：T+1个观测；image、wrist_image为uint8 RGB 256×256，遵循robosuite图像约定后执行[::-1,::-1]，与现有LIBERO推理预处理一致。
- state：8维float32，grip_site世界位置3＋轴角3＋按名字解析Left_1_Joint/Right_1_Joint的关节角2。原始6维夹爪关节、qpos/qvel、ctrl、qacc_warmstart、夹爪内部目标和仿真时间另存，便于审计。
- transitions：T个实际执行动作，7维归一化OSC，平移满量程0.05m、旋转0.5rad，夹爪−1开/+1合；20Hz，无动作裁剪/改写/滤波/抽帧。保存阶段、reward、环境done、动作前后qpos和时间。
- preparation：reset后120步静置的实际动作及前后qpos另存，不混入示范T帧；reset状态、最终运行XML、语言指令、随机种子、版本与文件指纹完整保留。
- 环境done是原生任务即时标志，可能在释放前已为true；不把它当作数据episode截断点。最后一帧为示范结束，保留完整释放后20步稳定窗口。
- 保留teacher/result.json、steps.jsonl、逐物理步physics.npz和接触记录；任务成功与数据审计通过分开记录。

本次不直接生成LeRobot、不计算全量训练归一化统计、不上传远端数据仓库。后续转换时须使用20Hz、7维原动作、任务语言、训练集独立norm stats，并避免跨episode拼动作块。

## 已知覆盖边界

原任务罐抓取位置基本固定；五个种子只保证独立尝试，不保证五个不同目标位置。报告完整场景哈希与目标包围盒去重数量；不可把此小批当作覆盖充分的数据集。上游初始化碰撞监测并未覆盖全部reset内部物理步，本采集器增加准备动作状态记录，但不声称解决碗的初始化问题。
