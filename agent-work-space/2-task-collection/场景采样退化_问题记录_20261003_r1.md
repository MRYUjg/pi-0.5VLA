# 原生目标采样退化为单点：问题与处理

日期：2026-10-03。基于pilot_20261003_r1试采后的场景覆盖检查。本次新实现独立放在coverage_20261003_r1，原冻结版本不变。

## 发现

上一批五条示范均成功且数据审计通过，但目标罐的初始位置在1mm精度下只有一个取值。仅依赖不同seed或完整qpos的SHA256，不能证明场景覆盖；浮点尾数变化也会产生不同哈希。

## 根因证据

目标初始区域在原任务BDDL中为：X=[−0.145,−0.095]m，Y=[−0.265,−0.215]m。`MultiRegionRandomSampler._sample_x/_sample_y`在`ensure_object_boundary_in_range=True`时，执行：

```
minimum += object_horizontal_radius
maximum -= object_horizontal_radius
```

alphabet_soup资产的`horizontal_radius_site`声明X半径为0.025m。因此有效X区间为[−0.120,−0.120]，Y区间为[−0.240,−0.240]：两个随机变量均退化为常数。这是采样参数与元数据组合的结果，不是seed没有生效，也不意味着物理仿真不存在随机初始化。

原始只读探针对53100、53101、54100三个seed分别记录采样器输出、reset状态和120步静置后状态。目标采样器输出始终为约[−0.120,−0.240,0.015]m；篮子采样值仍随seed变化。静置后的微小目标偏移来自接触动力学，不能用来代替主动覆盖。

注意：这里的25mm是资产采样元数据，不是对真实碰撞模型半径的重新测量。本次没有为扩大采样而修改物体的碰撞形状或尺寸。

证据：`runs/coverage_initialization_probe_r2/result.json`。早期r1探针在JSON序列化float32时失败，保留日志；r2仅修正序列化并重新运行，正常退出。

## 本次解决方式

建立显式scene清单，在reset原生placement sampler返回阶段应用目标XY、世界Z轴偏航增量及篮子XY，由原reset流程加载初态。其余原生物体、目标谓词、控制器和专家不变。操作只发生在初始化；示范执行期间不写物体或机械臂qpos，不添加焊接约束。

此处按物体中心定义覆盖区域，允许物体完整轮廓超出原小采样区域，所以明确登记为**受控初始化采集变体**，不冒充原始LIBERO测试分布。没有修改原BDDL文件，采集器保存覆盖前后的采样参数。

预登记9个train、3个validation、3个保留test场景。15个初始化检查均通过：静置后有15个毫米级可区分的目标中心，XY跨度约40.150/40.620mm，最小两场景距离约6.861mm。静置阶段逐物理步检查非支撑碰撞，保存实际位姿；任务成功仍须另外验证。

## 状态和边界

**单点退化已在新采集入口中绕开并验证了实际位置覆盖。** 原生采样器与原BDDL仍保留原行为。不能把该结论写成“原LIBERO采样器已被修复”或“所有新场景任务均已通过”；后者以正式批次的数据清单及完成记录为准。

验证/测试的目标位置与训练位置不同，但仍属于同一40mm尺度邻域；这只是小范围空间覆盖，不能证明广泛位置或视觉泛化。预留测试场景只做初始化检查，不采集教师轨迹；未来Spatial十任务正式测试另行冻结。
