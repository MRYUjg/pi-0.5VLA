## 转换语义

- 保持20Hz，无抽帧。图像为双256×256 RGB，以无损PNG嵌入Parquet，保持HDF5已有朝向，不再翻转、缩放、裁剪或有损编码。LeRobot读取返回float32的CHW/[0,1]图像。
- state保持8维：TCP世界位置3＋轴角3＋ZhiXing具名左右夹爪关节角2。最后两维不是Panda米制指爪位移。
- actions保持7维归一化OSC，平移满量程0.05m、旋转0.5rad，夹爪−1开/+1合；仅由float64存为float32，不做额外delta、不缩放、不反转、不裁剪。
- 语言写入task/task_index；episode、frame、global index及时间从0开始按20Hz登记。provenance记录原seed、scene、HDF5哈希、源仿真起始时间和帧区间。
- 每条源数据有T动作与T+1观测，仅导出T个(o_t,a_t)配对。共12个额外末端观测继续保留在原HDF5，不为其伪造动作；120步准备动作不导出。
- `next.done`只表示记录轨迹的最后一个动作。原环境可能在释放前报告done，转换不据此截断，保留原完整释放后稳定窗口。

## 通过的验证

| 检查 | 实测结果 |
|---|---|
| 两条开发预检 | train/validation各第一条；1,157帧、2,314张RGB全部通过 |
| 全量正式重载 | 12/12轨迹，6,947/6,947帧通过 |
| 双相机图像 | 13,894/13,894张与HDF5全帧逐像素一致，最大像素误差0 |
| 数值配对 | 每帧state和actions严格等于对应源数据的float32表示；索引、时间、语言、next.done均一致 |
| 动作精度转换 | float64→float32最大绝对误差1.4823028415822392×10⁻⁸；该误差单独记录，不写成原始float64完全不变 |
| 50步动作块 | 每条检查起点、中段及尾部等5处，共60组；末端只重复本episode最后动作，actions_is_pad正确，无跨episode取值 |
| CPU批加载 | train与validation均通过实际PyTorch DataLoader；actions [4,50,7]、state [4,8]、双图像 [4,3,256,256]、pad mask [4,50] |
| 数值统计 | 各repo的state/actions统计与该划分源帧独立重算一致，计数分别5,226和1,721；均值最大误差约2.57×10⁻⁷ |
| 错误帧拒收 | 动作、状态、图像、时间、末端标记、语言6种篡改均触发对应错误 |
| 错误源记录拒收 | 未通过审计、重复seed、test误入train三种错误均拒绝 |
| 已有输出保护 | 重复指定正式输出目录时拒绝运行；22个数据文件哈希在检查前后保持一致 |
| 源数据保护 | 转换前、转换后、读取验证后核对原始HDF5及相关来源证据哈希，未修改 |
| 冻结身份复核 | 原pilot 1,367项、coverage 1,505项、新转换版本112项指纹及归档核对均通过 |

正式转换耗时186.10秒、验证84.90秒，两阶段实际退出码均为0。上述时间不含安装依赖。已人工查看从LeRobot解码出的训练/验证双相机首、中、末帧预览。
