## 0. 先说结论

ZhiXing 夹爪的**开合方向、行程、四连杆平行度这三件事本身是对的**（与 N1/N2 记录一致）。
问题集中在**「力」和「可控性」**上：它基本是一个**只有两个状态的开环开关**，
闭到底时作动器几乎不出力，而且闭合过程中会把物体推偏、指垫扎进物体。

按对下游（P1 采集）的影响排序：

| 级别 | 问题 | 直接后果 |
|---|---|---|
| **P0** | 闭到底时作动器力≈0（位置伺服在行程端点没有误差 → 不产生夹持力） | 夹住后没有抗外力能力，物体易滑落 |
| **P0** | 控制律是 bang-bang，没有中间开度 | 没有力控/柔顺抓取，抓取只能"撞上去然后闭死" |
| **P0** | 闭合时物体被推偏 3.4–4.0 mm，指垫扎入物体 2.7–3.2 mm（超 2.0 mm 软限） | 抓取瞬间物体滑出指间；30 mm 试块能抬起但放不稳 |
| **P1** | 夹爪速度默认 0.2，部署值 0.01 只靠环境变量注入 | 忘记注入 → 闭合 5 步内完成 → 直接拨飞物体 |
| **P1** | 静态装配位（reset/-0.91）指垫互穿 0.477 mm，作动器已在 2.0 N·m 力限 | 初始状态就带着穿透与饱和力，不是干净的零位 |

## 2. 问题详情（每条都给实测证据）

### 2.1 闭到底时作动器几乎不出力（P0）

强制把 ctrl 钉在 −0.91 再推 500 步（`zhixing_close_limit.json` §S4）：

```
Left_1 = -0.9094（目标 -0.91）  →  位置误差 0.0006 rad
作动器力 = -0.046 N·m（forcelimited ±2 N·m，完全没饱和）
指垫净距 = 0.029 mm（已经到底）
500 步内关节角度波动 < 0.001 rad
```

原因很直接：作动器是**位置伺服**（`kp=100`，`forcerange ±2 N·m`）。
到行程端点后误差趋于 0 → 输出力也趋于 0 → **没有主动夹持力**，
只剩结构刚度。对比：静态装配位（reset）反而处在力限上（`actuator_force = 2.0 N·m`，
因为 5 条 equality 要求 −0.91 而四连杆把它顶在 −0.9098，误差被 equality 的刚度吃掉）。

**含义**：夹住任何东西之后，抗外力能力接近 0。这不是"夹不紧"，
而是"位置伺服在端点没有力输出通道"。要夹紧必须要么给力控/力矩下限，
要么把目标压到行程之外（现在被 `ctrlrange` 与 `jnt_range` 挡住，做不到）。

### 2.2 控制律是 bang-bang，没有中间开度（P0）

`zhixing_gripper.py: format_action` 为

```python
self.current_action = np.clip(self.current_action - self.speed * np.sign(action), -1.0, 1.0)
```

即**对命令取符号、按 speed 累积**，忽略命令幅值。实测（`zhixing_control.json` §A，各命令保持 400 步）：

| 命令 | current_action | ctrl | 指垫净距 |
|---|---|---|---|
| −1.0 | −1.0 | 0.00 | 89.49 mm（全开） |
| −0.5 | −1.0 | 0.00 | 89.49 mm（全开） |
| 0.0 | −1.0 | 0.00 | 89.49 mm（**保持上一次状态**） |
| +0.5 | **+1.0** | −0.91 | 0.035 mm（全闭） |
| +1.0 | +1.0 | −0.91 | 0.035 mm（全闭） |

- 命令 0 不改变状态：夹爪**没有"松开到某开度"的能力**，只能全开/全闭。
- 命令 +0.5 与 +1.0 等效：**任何 ≥0.5 的命令都会闭到底**。
- 命令 −0.5 与 −1.0 等效。

**含义**：动作的第 7 维实际只有 3 个有效状态（保持 / 全开 / 全闭），
策略学到的"半开"指令不会被控制器执行；力控/柔顺完全不存在。

### 2.3 闭合把物体推偏 + 指垫扎入物体（P0）

同一脚本专家链路、30 mm 试块、同样初始位置（`expert_ZhixingGripper_w30_20260929_073109.json`）：

| 量 | ZhiXing | Panda 对照 |
|---|---|---|
| 闭合段指垫穿透峰值 | **2.73 – 3.21 mm**（超 2.0 mm 软限） | 0.867 – 0.908 mm |
| 闭合瞬间物体位移 | **2.7 – 4.0 mm** | 0.07 – 0.61 mm |
| 抬升 | 74.0 – 75.0 mm（能抬起） | 76.6 – 78.1 mm |
| 投放/释放稳定 | **0/4 通过** | 4/4 通过 |
| 原生谓词成立 | 0/4 | 4/4 |

闭合瞬时指垫间距锁在 **Object_Width − 2.7~3.2 mm**，
说明不是"夹住"而是"**扎进物体**并把物体挤到一侧"。
这与上一轮 `n3_osc_full_chain` 里 ZhiXing 的 `obj_shift_on_close` 3.3–4.0 mm 完全一致。

### 2.4 夹爪速度默认值与会话状态（P1）

- 资产默认 `speed = 0.2`（`ZHIXING_GRIPPER_SPEED` 未设置时）→ 闭合 **5 个控制步（0.25 s）** 到底；
- 部署值 0.01 → 100 步（5 s）到底，实测闭合段稳定（穿透 0.03 mm 级）。
- 同一个 30 mm 试块：**speed=0.2 时穿透 17–23 mm、抬升 0、0/15 全部失败；speed=0.01 时可抬起 74 mm**。
- 该值只由环境变量/`n4_collect.py --gripper-speed` 注入，**没有写进资产默认**，
  也没有在任何"夹爪契约"里作为运行前提校验（`configs/frozen_protocol.json` 里记了 `gripper_speed: 0.01`，
  但运行入口不检查实际生效值）。

### 2.5 静态装配位自带穿透与力饱和（P1）

`zhixing_close_limit.json` §S1/§S2（写 qpos 与 reset 完全一致）：

```
Left_1 = -0.9100，6 关节 = [-0.91, 0.91, -0.91, 0.91, 0.91, 0.91]
指垫净距 = 0.1799 mm
指垫自接触：gripper0_left_fingerpad_col × gripper0_right_fingerpad_col，穿透 0.477 mm
作动器力 = 2.0 N·m（= forcerange 上限，已饱和）
```

即**零位就是"两片指垫互相插进去 0.48 mm"**，且作动器一直顶在力限上。
这解释了为什么 `arm_info`/探针里 reset 就带着 1 个自接触。
（N2 契约把 closed 记为 `not_reproduced` 的正是这一族现象。）

### 2.6 开口口径复核（记录我自己的度量缺陷）

`zhixing_aperture_metric.json` 用**真实 mesh 顶点**重算：

| 状态 | 指垫净距（真实顶点，修正口径） | 我之前的口径（几何中心距） |
|---|---|---|
| reset / 静态闭合位 | **0.1799 mm** | 17.80 mm ❌ |
| 命令 −1 全开 | **89.4914 mm** | 107.78 mm ❌ |
| 命令 +1 动态闭合 | **0.0346 mm** | 18.27 mm ❌ |

原因：`jaw_gap_mm()` 的 `surface_points()` 对 **mesh 类型 geom** 退化成"几何中心"，
而 ZhiXing 的两个指垫 geom 恰好是 `type=mesh`（`Left/Right_Support_Link` 网格）。
Panda 的指垫是 box，所以没受影响。

**影响范围（必须记账）**：`outputs/SUMMARY.md` 与 `outputs/comparison.*` 里
ZhiXing 的"开口"列（17.8/18.27/107.78 mm）**是错的**，应改为 0.18/0.035/89.49 mm；
但两处关键结论**不受影响**：① 试块宽度预算当时取自 `min(请求, 开口−4)`，
修正后 ≤ 请求值，试块实际宽度不变（Panda 全部 30.0/25.0/36.7 mm，ZhiXing 均为 30.0 mm）；
② ZhiXing 0/4、Panda 4/4 的任务级结论与开口无关。

### 2.7 指根最小间距 ~17.8 mm（P2，待专项确认）

修正口径下，**两个指垫网格之间**的最小点对在"全开"状态下是 89.5 mm，
但**同侧不同部件**之间仍存在 ~17.8 mm 的最近距离（在 `min_clearance` 口径里可见）。
需要专项确认这段 17.8 mm 是否位于夹持区（若是，则物体宽于 17.8 mm 时只有指尖一小段能夹）。
本轮**未做**该专项，故只作为待查项列出，不给结论。
