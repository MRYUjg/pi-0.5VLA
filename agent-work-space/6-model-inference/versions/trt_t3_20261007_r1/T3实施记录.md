## 结论与授权边界

T3 已完成：AWQ 主候选和 GPTQ 对照的 prefix INT4 TensorRT 引擎均成功构建，121 个目标量化源层全部有实际执行证据，两套引擎的独立进程重载动作误差均为 0。AWQ 的 128 观测离线数值门槛通过；GPTQ 的夹爪方向分歧为 7/1280，超过 0.5% 门槛，不能作为当前合格主候选。

用户本次授权原文为“暂时允许这个情况，继续实施T3”。允许的是既知 T1 浮点后端夹爪边界漂移，不是修改原验收门槛。T1 原始越界率增量仍为 1.116071 个百分点，超过 1 个百分点，原失败记录继续保留。本次没有放宽新量化误差、夹爪判定、控制器参数或数据采集行为。

本阶段未执行 T4 闭环、T5 目标 4070/8GB、T6 正式 200 次测试或 T7 实机。通过 T3 和文件冻结，不代表已达到高成功率机械臂适配或生产部署验收。

## 输入、环境与模型范围

采用冻结的 T0–T2 产物，旧 release manifest SHA256 为 `4f359c7b939e10c7eebba4213f4156aef7dc02874101c9919f9ad0a3222c23ee`。源 `pi05_libero` BF16 值权重 SHA256 为 `69ee787ec12921613feabf69b01348628b3d6327a8865cbc02ecb9be788d9258`。本次没有 ECO65+ZhiXing 微调模型参与。

校准来自 Panda+PandaGripper 的 LIBERO Spatial 教师轨迹：2000 个选定观测，10 个任务各 200 个。T3 使用同一冻结的 128 观测 pilot，每个观测生成 10 个动作，原噪声种子、图像、语言、归一化与反归一化保持一致。pilot SHA256 为 `3e4a3cae16408dca1b883d0661f9dafe5db2d79f473a018b7b0c6067235ce074`。这些观测存在轨迹内时间相关性，既不是独立成功率试验，也不是额外泛化集。

环境：RTX 4090 49140MiB、驱动 535.129.03、TensorRT 10.13.3.9、Torch 2.7.1+cu126、ModelOpt 0.33.1、Transformers 4.53.2。使用原冻结镜像 `pi05_trt:20261007-r1`，镜像 ID 为 `sha256:cf96556ab8b55eb3f80770d2a684d6961c0128c8100660a8cc4c7e61ecc60369`。`environment_r1/runtime.json` 验证了与 T0–T2 相同的包版本、原项目代码、相关 Transformers 补丁和 tokenizer 内容。仓库只读挂载，只有本次新目录可写；没有更换驱动或系统 CUDA。

只量化 prefix 内实际可达的 121 个 language Linear（1,872,756,736 个参数），权重为对称 signed INT4、group size 128，保留原浮点激活。T2 有 126 个候选源 Linear，其中最后一层的 5 个不参与所需 KV 输出，导出后裁除；不能把这 5 个算作运行覆盖缺失。vision 与 action expert 继续使用 T1 浮点引擎。

AWQ 为官方 ModelOpt 校准路径作用于受控 Linear 的结果；GPTQ 为记录了 Hessian 阻尼和误差补偿的受控 Linear 实现。本次把这些已有真 INT4 ONNX 权重导入 TensorRT，不宣称 TensorRT 自动完成了整个 pi0.5 的 AWQ/GPTQ 算法。

## 构建与实际执行覆盖

构建使用强类型网络、TF32 关闭、2GiB builder workspace、优化等级 3、DETAILED 层信息和 editable timing cache。2GiB 是构建器允许的工作空间，不是推理总显存上限。AWQ 保存新 cache，GPTQ 在匹配环境下继承并更新 cache。原 ONNX 及外置数据在构建前通过旧 release 哈希校验。

| prefix context 工作空间字节数 | 117,522,432 | 115,978,240 |

AWQ prefix engine SHA256 为 `14f0e9f94d4c500e3b18cd7eea89773e4e04eb4316a3dd3ba4c61f046bab8169`；GPTQ 为 `09bc51f20fb652b2b9f4dbb731addeb1ec1f33e0d6fc51fec6a2219a43b64c6c`。引擎和 timing cache 的精确哈希、接口形状与层信息分别保存在 `build.json`、`registration.json`、`engine_layers.json` 和 bundle 中。

TensorRT 会合并部分 GPTQ Q/K/V 或 gate/up 矩阵，121 个源层对应 69 个唯一 GEMM。这不表示 52 个源层未执行。审核对照 ONNX 元数据、生产者边、合并后矩阵尺寸与原始权重导出核验，再用一次完整 10 步暖请求的 IProfiler 回调验证实际执行。原映射失败尝试保留，没有把仅凭缺少编译后节点名的结果当作权重量化失败，也没有省略未通过日志。

这是 **INT4 权重存储压缩 + 浮点激活计算**。存在明确的独立反量化执行路径；融合路径的 GEMM tactic 也标明 BF16 输入及浮点累加。因此不能宣称 121 层都使用纯整数 INT4 乘加或都获得融合加速。[TensorRT 精度说明](https://docs.nvidia.com/deeplearning/tensorrt/10.x.x/inference-library/precision-control.html)和[引擎审计说明](https://docs.nvidia.com/deeplearning/tensorrt/10.x.x/inference-library/engine-tools.html)是所采用的官方接口依据。

## 推理实现与独立重载

运行时一次只加载一套策略的 vision、prefix、action_step 引擎；不加载或实例化原始浮点 pi0.5 模型。Torch 仅用于预处理、缓冲区、原时间嵌入和 Euler 更新等辅助操作。

三段采用一个非默认 CUDA stream 串行执行。context 使用用户管理内存，按三段最大需求分配一个对齐的共享工作空间，每段同步后再复用。每张图像的 vision 输出在缓冲区重用前复制；prefix 的 36 个 KV 输出与工作空间分开，10 步 action 推理期间只读。每个验证观测都逐位检查 KV 未被写坏。

保留原 10 次去噪步、FP32 Euler 更新、原时间 helper 的 FP64 中间计算转 FP32、输入遮罩和反归一化。内部最终动作形状为 `[1,10,32]`，环境动作 `[10,7]`。所有分数均在 `np.clip` 之前计算，未通过先夹紧再评分掩盖边界偏差。

| 独立进程复现项 | AWQ | GPTQ |
|---|---:|---:|
| 实际观测数 | 128 | 128 |
| 最终内部动作最大绝对差 | 0 | 0 |
| 10 步 velocity field 最大绝对差 | 0 | 0 |
| 环境动作最大绝对差 | 0 | 0 |
| 同引擎 SHA、不同进程 PID | 通过 | 通过 |
| 所有输出有限、KV 未改变 | 通过 | 通过 |

既定重载门槛为最终内部动作最大绝对差 ≤1e-6，两套均通过。新 float 运行时还逐位复现了原 T1 的 128 观测输出，环境动作最大差为 0，说明本次共享缓冲区和预处理实现没有另引入数值偏移。这是相同冻结引擎的重载一致性，不是不同硬件或重新构建引擎必然逐位一致。

## 离线数值结果

运动误差按 6 个运动维度的环境动作差绝对值除以 2 统计；夹爪只统计参考值绝对值 >0.2 的 1280 个动作。原门槛保持为运动 MAE ≤0.01、p99 ≤0.05、夹爪方向分歧 ≤0.5%、7 维动作总体越界率增量 ≤1 个百分点。

| 比较 | 运动 MAE | 运动 p99 | 夹爪分歧 | 越界率增量（百分点） | 原门槛 |
|---|---:|---:|---:|---:|---|
| TensorRT float → AWQ | 0.002899 | 0.022642 | 6/1280，0.46875% | -0.223214 | 通过 |
| 原 PyTorch → AWQ（累计） | 0.002932 | 0.023297 | 6/1280，0.46875% | +0.892857 | 通过 |
| TensorRT float → GPTQ | 0.004878 | 0.037819 | 7/1280，0.546875% | -1.651786 | 未通过夹爪项 |
| 原 PyTorch → GPTQ（累计） | 0.004885 | 0.037442 | 7/1280，0.546875% | -0.535714 | 未通过夹爪项 |

参考 PyTorch 有 327 个夹爪动作越界，T1 float 为 427，AWQ 为 407，GPTQ 为 279；六个运动维度都没有越界。AWQ 在本组样本上的累计越界增量降到门槛内，不能据此改写 T1 自身失败结论。

AWQ 累计运动最大单点误差约 0.1011，GPTQ 约 0.2035，虽然 MAE/p99 门槛通过，仍存在误差尾部。128 个相关观测和夹爪 6/1280 接近门槛的结果需要后续独立数据与闭环测试；不能把数值门槛通过表述为任务成功率无损。

## 保留的失败尝试、冻结与下一阶段

`gptq_infer_r1` 因误写 pilot 目录在读取输入时失败，未开始模型推理；修正路径后的 `gptq_infer_r2` 完成全部验证。`gptq_coverage_r1/r2` 因未识别编译器合并后的 DQ 来源而失败；`gptq_coverage_r3` 加入生产者边和合并矩阵尺寸追踪后通过，并获得真实执行回调佐证。`awq_infer_r1` 曾因 TensorRT 的 profiler setter 不接受空指针产生 API 日志错误；后续默认不挂 profiler，诊断路径保留 owner 并关闭自动报告，`awq_infer_r2` 与两套重载是当前有效结果。原尝试、错误日志、真实退出码和每次源码快照全部保留。

引擎与 bundle 在使用前已设只读。全部新源码、报告和运行文件由 `releases/trt_t3_20261007_r1/manifest.json` 绑定，服务器完整校验同时核验此前冻结依赖；本地只镜像小文件，单独记录部分镜像校验，明确缺少大模型、引擎与数据文件。此前冻结的 T0–T2、r4 方案和根 README 没有覆盖。专属容器在所有推理任务结束后停止，关闭回执保存在 `container_shutdown.json`。

后续如授权 T4，应使用 AWQ 新建版本接入 Panda+PandaGripper LIBERO 闭环，保留同环境 float 对照、固定初始条件与种子，记录动作、视频和实际成功率。T5 再在目标 4070 的 8GB 预算下重建，验证完整单模型路径显存、延迟和稳定性；T6 才进行 10 个任务各 20 次独立测试及 ≥90% 成功率判定。GPTQ 当前质量项保持未通过，不因为 T1 临时例外而自动进入主线。
