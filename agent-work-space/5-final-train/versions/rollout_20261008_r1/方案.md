# π0.5 独立闭环测试 — 20261008 r1

用户明确要求进行闭环测试，并记录 MP4。本轮在 5-final-train 新建独立版本，既有冻结源、训练、选模、归一化和采集记录不覆盖。候选为验证损失已选定的第 10000 步权重；不使用 test 重新选择检查点。

沿用先前登记的 LIBERO Spatial 十任务各 20 个独立测试 seed。四组比较分别为 ECO65+ZhiXing 微调、ECO65+ZhiXing 基座、ECO65+Panda 基座、Panda+Panda 基座，每组 200 次。报告五个已训练任务和五个未训练任务、逐任务成功率、固定分母总成功率、Wilson 95% 区间、失败类型及进程异常。

原生 reset(seed)，不替换失败种子、不改变物体采样、不注入老师状态。保留全部尝试；初态审核不通过也留在 20 次分母中。技术烟测发现 Panda 零初始化噪声仍消耗7个高斯数、ECO65消耗6个，因此同seed不等同于相同对象场景。正式评测在Panda进程中仅对该零噪声RNG消费对齐为6个数，不改初始化关节角、不写对象状态、不改变物体原生采样器；各组物体reset哈希独立核对，若有差异如实披露。该协议使用已登记随机采样测试种子，不能描述成官方 LIBERO .pruned 固定初态基准成绩。

准备期复用冻结 quiet_hold 的 120 步、0.02m/0.05rad 增益、开爪 -1 和 legacy profile；使用 collection_20261005_r4 的原初始化审计，阈值不变。按冻结 replay.py 在第一个准备控制步结束后创建 render context，保持与采集链路相同的首次创建时序；其后仅在推理与录像需要时渲染，不生成无用准备期图像。该初始化包含 proprioceptive settling，不运行任务老师，不通过对象状态生成策略动作。

执行期 ECO65+ZhiXing 保持 eco65_no_extra_pd、夹爪速度 0.01；Panda 对照和 ECO65+Panda 使用已有 legacy 配置。20Hz，输出七维原生 OSC，实际平移/旋转满尺度 0.05m/0.5rad；每 5 步重新推理，采样 horizon10、去噪10步，未重复 delta。保留归一化/反归一化和 LIBERO 输入输出变换，原 checkpoint 参数 dtype 不改变。模型条件是图像与文字，state 数值不进入网络条件。

主评测预算保持现有 Spatial 入口的 220 步。原生任务目标在 220 步内成立、初始化审核通过、物理状态有限且无警告、进程退出0才计成功。每组每任务预登记第一条延长至最多650步，作为较长教师时序的独立诊断；超过220步的成功不能计入主成功率。执行期每个物理子步记录最大接触穿透/力；这不能冒充完整 r6 教师轨迹物理认证。

每个条件每个任务的第一条尝试保留真实双视角 MP4，20fps，含条件、任务、seed、步号；不按成功与否挑选、不覆盖失败视频。初态拒绝录像保留静态初态一秒并明确标注拒绝原因。动作、qpos/qvel、推理时的真实 RGB/状态、完整输出动作块、噪声指纹与实际执行动作均保留，以便独立核对。视频验收包括全文件解码、帧数和 SHA256。

推理使用按 episode seed 和 query 编号派生的固定 diffusion noise，避免并发请求顺序改变实验。一个 GPU 服务串行推理，最多六个 CPU 仿真客户端；不运行老师干预或人工接管。候选版本固定后消耗 test；本轮结果不能用于原地调参，再训练需要新的开发验证和未使用测试集。
