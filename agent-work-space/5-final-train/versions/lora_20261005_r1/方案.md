# 正式 π0.5 LoRA 训练 r1

只接收 formal_20261005_r1 放行数据，先逐帧 LeRobot 回读；训练、验证、保留测试种子互斥。归一化统计仅计算训练数据。每个任务至少 20 条训练、4 条验证示范，否则停止本批训练。旧单任务数据不隐式混入。

基座 pi05_libero，action_horizon=10，batch=4，10,000 步，学习率 1e-4，200 步 warmup，余弦衰减到 1e-5，梯度裁剪 1。仅训练两个语言/动作分支 LoRA，冻结所有非 LoRA 参数，包括视觉。保持官方本地基座配置 discrete_state_input=False：8D 状态保留在数据接口中，模型实际条件为图像和语言，不能宣称本实验模型读取了本体状态。

按任务轮转均衡采样，任务内均匀选 episode、再均匀选帧；验证每条 episode 固定四个时刻、固定噪声。每 2,000 步保存并评估，以各任务验证损失的等权平均选择 checkpoint。保留测试种子不参与采集、统计、调参、选模。

先运行真实数据 batch=4 的三步资源探针，不保存其权重；通过后从基座重新启动正式训练。全过程记录损失/梯度/资源。检查非 LoRA 参数字节不变、LoRA 确实更新；独立进程重载选择 checkpoint，验证参数逐字节、同噪声动作误差 ≤1e-5，并执行一次不覆盖原权重的恢复训练。训练和重载共享持久 JAX 编译缓存。

训练成功不等于策略闭环成功。旧第 3 阶段闭环结果 0/3 不作废，也不据训练损失推断本阶段成功率；后续必须实测。本轮首先交付可复核的数据、权重、执行记录和每个任务一个真实录制 MP4。全 Spatial 10×20、总成功率≥90% 的最终验收尚未完成。
