# 正式采集与 π0.5 LoRA 微调方案（20261005 r1）

目标：在 5-final-train 独立开展成功教师任务的数据采集、审核、转换、训练和闭环验证。当前只覆盖 Spatial 0、2、3、5、6、8；失败任务 1、4、7、9 未修复，不计作完整十任务高成功率适配。

采集：逐任务 3 个新开发回归 seed；暂定逐任务 50 个 train、10 个 validation 尝试；原生 reset(seed)，保持采样器、物理资产、控制器、夹爪速度及 r20 教师不变。失败原样保存，不重抽替代、不计入训练。参考 seed 57100/2/3/5/6/8 仅检查新增观测审计是否改变初态，不进入训练。十任务各 20 个 test seed 单独预留，不执行教师、不用于归一化/选择检查点。

数据放行：新增只读初始化审计，依实际 BDDL 初始 On/In 关系识别支撑，最后 20 个准备控制步需持续满足原生初始谓词；最后一秒位置漂移 ≤5mm、转动 ≤5deg；准备阶段非声明支撑穿透 ≤1mm、声明支撑穿透 ≤2mm（不豁免合法支撑的过深穿透）；机器人外部接触法向力 ≤0.1N；初态目标不得已成功。该审计是新增放行条件，不能取代原 r6 轨迹数值复核。若失败先定位，不自动放宽。

每条正式示范还必须正常退出、教师 success、全部原门限成立、r6 物理审计通过、T+1/动作/state/双 RGB/文本/时序一致、从 reset 重放实际动作通过原误差阈值。规划拒绝的空轨迹不进入训练。回归通过后才放行正式采集；训练/验证/保留测试按 seed 隔离，并检查初始状态重复和真实位置覆盖。

资源：当前 A100 40GB、16 vCPU、约32GB RAM、287GB可用磁盘。采集最多六个 CPU 容器，各上限2 CPU/4GB；正式训练不与采集争抢内存。每条保存真实状态、源码指纹、失败原因，支持跳过已完成条目继续执行。保留每任务至少一段真实 MP4。磁盘不足40GB时暂停新增任务并报告。

训练：复用已验证的 pi05_libero JAX LoRA 链路；state=TCP xyz/rotvec+指定夹爪两关节角，actions=原归一化 OSC 7维，horizon=10，不重复 delta 变换。只允许已审核成功示范；按任务平衡取样；仅训练数据计算归一化，验证使用同一统计量。初始拟采用 batch4、10000更新、LoRA-only、AdamW、warmup200、peak_lr1e-4、梯度裁剪1、EMA关闭；以实际资源烟测确认后冻结训练版本。保留阶段检查点及固定验证指标，按验证结果选择，不用测试调参。独立进程验证保存/恢复，随后做仿真闭环，报告模型成功率与教师成功率的区别。

阶段：A 上游指纹与初始化审核 → B 新场景教师回归 → C 正式尝试及逐条审核 → D LeRobot 全量读取验证 → E 训练/检查点重载 → F 独立闭环。任何未通过项保持未通过，后续依赖阶段不自动绕过。预计采集可能耗时数小时至十余小时，按当前真实单条耗时再更新估算。


r2 修复：LIBERO 桌面 region 的 parent_name 为 None，按实际 workspace_name=main_table 解析。r1 初始化分类器在采样前抛异常，保留原失败；未产生正式训练数据。未更改任何审核数值阈值或物理状态。
